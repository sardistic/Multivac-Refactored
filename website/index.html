MULTIVAC

I built this for a few Discord servers I hang out in. You @ it and it answers, with GPT, Gemini or Claude depending on the question. It searches the web when it doesn't know something, reads whatever link or YouTube video you paste, draws pictures, makes short videos, and remembers things about you if you ask it to. It forgets them when you ask, too.

What it does

Chat, by mention or reply

Talk to it like anyone in the server. It keeps the thread, follows replies, and picks the model the task needs.

Images

Generate, edit and describe images, analyse attached files, and work from reference images.

Video

Sora and Veo generation, image-to-video from a reference, Sora remixes, and prompts drawn from the message you reply to.

Real tools

Web and reverse-image search, weather, stocks, URL summaries, YouTube transcripts and repository inspection, inside bounded loops.

Memory, scoped to you

Facts you ask it to remember, saved behaviour instructions and optional long-term recall, all kept per user and forgettable on request.

Honest progress

Live progress for long jobs, with real phase details and estimates, and a status record of exactly which tools ran.

Memory & privacy

Remembered facts, instructions and recall are scoped to the person, channel and server they came from. Traces of what the bot did keep orchestration metadata and public evidence links, never your prompts, attachments, memories or credentials.
